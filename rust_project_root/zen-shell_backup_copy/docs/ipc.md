# zen-shell IPC commands

The running bar binds a unix socket at `$XDG_RUNTIME_DIR/zen-shell.sock` and
serves line commands. Any external tool — a Hyprland keybind, a script, a
launcher — can poke it with the same binary acting as a client.

```
zen-shell <command>          # client form
zen-shell ipc call <handler> # quickshell-compatible form
```

## Open a widget

| Command | Opens |
|---|---|
| `zen-shell open launcher` | app launcher (search apps) |
| `zen-shell open cc` | control center (wifi/bt toggles, volume, brightness, audio, wallpaper) |
| `zen-shell open notifications` | notifications panel |
| `zen-shell open calendar` | calendar |
| `zen-shell open settings` | settings (wifi/bt, sliders, accent, stats) |
| `zen-shell open power` | power menu (hold 3s to act) |
| `zen-shell open wifi` | wi-fi network list |
| `zen-shell open bluetooth` | bluetooth device list |
| `zen-shell open audio` | **per-app volume** (output + input devices, app streams) |
| `zen-shell open wallpaper` | **wallpaper picker** (thumbnails from `[wallpaper] dir`) |
| `zen-shell open weather` | **detailed weather** (feels like, humidity, wind, rain) |
| `zen-shell open clipboard` | **clipboard history — text** (SUPER+V) |
| `zen-shell open clipboard_images` | **clipboard history — images** (SUPER+SHIFT+V) |
| `zen-shell open themes` | **theme picker** — cards from `$states2/themes` (JSON mirror of the bash master); click sources `$states/themes` inline + calls `theme_main restore` (SUPER+T) |
| `zen-shell open keybinds` | **keybind viewer** — read-only list from `$states2/keybinds_cache` (JSON `{key,desc}[]` generated by `gen_keybinds_cache` from `~/.config/hypr/keybinds.lua`; SUPER+SHIFT+/) |
| `zen-shell open expanded` | the dashboard (as if hovered) |
| `zen-shell wallpaper set <path>` | set the **wallpaper daemon** background (cover-fit, fade-in) |
| `zen-shell reload` | **hot-reload ALL configs** — re-read the channel + its `$states/shell_{n,d,l}` (pill toggles, geometry, colors, animation, anchor/floating/reserve) and re-apply the bar layer (no restart needed) |
| `zen-shell reload colors` (= `zen-shell colors reload`) | **palette-only hot reload** — re-read every color from `$states2/shell_vars.json` and redraw. Never touches config/geometry/dashboard, so it can't break a live session (call after a theme pipeline run; also self-invoked ~1.5 s after an apply/switch) |
| `zen-shell ipc call mode sync` | re-read the **dark/light state from `$states2/m_dummy`** (`d` = dark, `l` = light) so the dashboard toggle chip matches reality |
| `zen-shell open lock` | **lockscreen** (ext-session-lock: compositor keybinds stop, all input swallowed, blurred-wallpaper bg; type your user password + Enter to unlock; logout / restart / shutdown hold) |
| `zen-shell close` | collapse back to the pill |

Aliases: `notif` = notifications, `cal` = calendar, `bt` = bluetooth,
`volume` = audio, `wallpapers` = wallpaper, `collapse` / `pill` = close,
`themes` / `theme` = theme picker, `keybinds` / `kb` = keybind viewer,
`expanded` = dashboard. The sync handlers also answer as plain
commands: `zen-shell colors` (= `colors reload`) and `zen-shell mode sync`.
Handler aliases: `colors` / `reload_colors` / `sync_colors`, and
`mode` / `mode_sync` / `sync_mode`.

## Toggle

`zen-shell toggle launcher` opens the widget, or closes it (back to the pill)
if it is already the current one. Any `open` target works.

`zen-shell open <target>` toggles exactly the same way: a second call while
the widget is already up collapses back to the pill (so a single keybind can
open *and* dismiss the launcher).

## Quickshell-style

The `ipc call` forms work too, including the single-name handlers:

```
zen-shell ipc call open power
zen-shell ipc call launcher     # ≡ zen-shell ipc call open launcher
zen-shell ipc call close
zen-shell open power            # plain form is equivalent
zen-shell open launcher
```

## Replies

The server replies on the same socket: `ok`, or `error: <reason>` for an
unknown handler (the client exits 1 then).

## Hyprland keybinds

```
bind = SUPER, SPACE, exec, zen-shell open launcher
bind = SUPER, L,     exec, zen-shell open lock
bind = SUPER, P,     exec, zen-shell open power
bind = SUPER, A,     exec, zen-shell open audio
bind = SUPER, W,     exec, zen-shell open wallpaper
bind = SUPER, T,     exec, zen-shell open themes
# after a script-driven theme change, make the bar pick the palette up:
bind = , X,          exec, zen-shell ipc call colors reload
bind = SUPER, ESCAPE, exec, zen-shell close
```
